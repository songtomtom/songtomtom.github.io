## 프로젝트 설정

프로젝트 디렉토리를 만들고 Go 모듈로 초기화 합니다.

```bash
mkdir rest_api
cd rest_api
```

## OpenAPI Generator

GraphQL Mesh REST API 스키마를 통합하기 위해서는 OpenAPI 정의 파일이 필요합니다.

OpenAPI Genrator 를 설치 합니다.

```bash
brew install openapi-generator
```

GraphQL Mesh 예제에서 [openapi3-definition.json](https://github.com/charlypoly/graphql-mesh-docs-first-gateway/blob/master/packages/books-service/openapi3-definition.json) 파일을 가져옵니다.

- GET /books/:id
- GET /categories

OpenAPI Genrator 를 통해 파일을 생성합니다.

```bash
openapi-generator generate -i openapi3-definition.json -g go-gin-server
```

파일이 성공 적으로 생성된 경우:

```text
.
├── Dockerfile
├── api
│   └── openapi.yaml
├── go
│   ├── README.md
│   ├── api_books.go
│   ├── model_book.go
│   ├── model_category.go
│   └── routers.go
├── go.mod
├── go.sum
├── main.go
└── openapi3-definition.json
```

OpenAPI Generator 가 생성한 main.go 는 sw "./go" 코드에 에러가 발생합니다.

`main.go`

go.mod 파일에 정의한 모듈 주소에 따라 수정합니다.

```go

```

또한 .meshrc.ymal 에서 정의한 포트 3002 로 수정합니다.

`main.go` — 오류 수정후

## REST API 스키마 통합

REST API 서버 스키마를 통합 하려면 /mesh-gateway 프로젝트로 이동하여 @graphql-mesh/openapi 종속성을 추가하고 .meshrc.ymal 를 수정합니다.

```bash
yarn add @graphql-mesh/openapi
```

package.json

```json
{
  "dependencies": {
    "@graphql-mesh/cli": "^0.82.11",
    "@graphql-mesh/openapi": "^0.35.7",
    "graphql": "^16.6.0"
  },
  "scripts": {
    "start": "mesh start",
    "build": "mesh build"
  }
}
```

`.meshrc.yaml` — openapi 만 메시게이트웨이

```yaml
sources:
  - name: Books
    handler:
      openapi:
        endpoint: http://localhost:3002/
        source: ../rest_api/openapi3-definition.json
#  - name: Authors
#    handler:
#      grpc:
#        endpoint: http://localhost:3003/
#  - name: Stores
#    handler:
#      graphql:
#        endpoint: http://localhost:3004/
serve:
  hostname: 0.0.0.0
  port: 80
  endpoint: /
  browser: false
  playground: true
```
